# 数据结构课程设计

课程设计安排在第 17 周。具体题目公布前，本目录用于积累候选方案和可复用模块。

## 预期交付

- 需求分析
- 数据结构选择及理由
- 算法设计与复杂度分析
- C 语言实现
- 测试用例与结果
- 使用说明
- 课程设计报告与答辩提纲

## 过程要求

- 不在第 17 周才开始准备。
- 从平时练习中保存可靠的线性表、栈、队列、树和图模块。
- 每个模块都必须包含边界测试和内存释放。
- 选题以任课教师要求为准。

## 分阶段准备

| 时间点 | 阶段产物 |
|---|---|
| 第 8-12 周 | 保存经过测试的线性表、栈、队列、树或图模块，并记录可复用接口 |
| 第 13-15 周 | 收集候选题目，判断需求、数据结构、输入规模和实现风险 |
| 第 16 周 | 完成需求草案、结构选择理由、模块划分和测试计划，接受方案评审 |
| 第 17 周 | 按教师题目完成实现、测试、报告和答辩材料 |

若教师在更早时间公布题目，以教师时间点为准提前执行；没有公布题目时只准备通用能力，不虚构正式需求。
