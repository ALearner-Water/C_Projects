# LeetCode 练习区

## 做题规则

1. 默认使用 C 语言。
2. 先独立思考 15-25 分钟，再申请提示。
3. 不直接复制题解；需要帮助时采用分级提示。
4. 提交通过后补写思路、复杂度和边界用例。
5. 一道题只有在 7 天后能够独立重写，才算真正掌握。

## 分级提示

- 一级：指出相关数据结构或关键观察。
- 二级：给出算法步骤，不给代码。
- 三级：给出伪代码或关键 C 语句。
- 四级：共同完成代码，并在第二天从空白重写。
