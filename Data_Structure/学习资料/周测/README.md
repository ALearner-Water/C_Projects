# 周测区

周测默认 30-45 分钟，闭卷完成。优先安排在周六上午并在 12:20 前结束；周六 12:50 后不启动高强度任务，下午固定课程结束后不补量。若周六上午不可用，则顺延到下一个无冲突时段，不压缩睡眠或挤占更高优先级课程。

周测只覆盖已经完成初次教学和练习的内容，不用尚未讲授的知识制造分数。概念表达、代码阅读和空白实现分别计分。

## 标准结构

- 概念辨析：20%
- 手算或执行过程：20%
- 复杂度分析：20%
- 代码阅读与纠错：20%
- 编程或算法设计：20%

## 评分后的处理

- 90-100：进入下一模块，并保留一道迁移题。
- 75-89：正常推进，针对薄弱点补一组练习。
- 60-74：部分回炉后再推进。
- 60 以下：重新讲解核心概念并安排二次测试。

成绩只用于调整学习路线，不用于评价个人能力。

## 记录要求

每次周测记录日期、覆盖范围、实际用时、各能力项得分、错误类型和补救动作。只有学生答卷、代码或运行结果可以作为成绩证据；未参加不记零分，标记为顺延。
