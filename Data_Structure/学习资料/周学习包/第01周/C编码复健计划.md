# C 编码复健计划

目标不是重新学完 C 语言，而是恢复数据结构课程立即需要的编码能力。

| 次数 | 主题 | 必须能独立完成 | 验收任务 |
|---|---|---|---|
| 1 | 函数、循环与数组 | 函数定义、遍历、边界初始化 | 重写 `max_value`，通过负数数组测试 |
| 2 | 地址、指针与解引用 | 区分 `a`、`*a`、`&a` | 实现 `swap` 并解释每个表达式的类型 |
| 3 | 结构体与结构体指针 | 定义结构体，使用 `.` 和 `->` | 定义 `Student` 和 `Node` |
| 4 | 动态内存 | `malloc`、`sizeof`、判空、`free` | 实现并测试 `create_node` / `destroy_node` |
| 5 | 综合衔接 | 函数 + 指针 + 结构体 + 动态内存 | 从空白写出最小单链表并通过测试 |

## 视频安排

- 主讲课程第 2 集包含指针、结构体、动态内存和复杂度，拆分到第 2-4 次复健，不整集观看。
- 王道短视频只用于数据结构概念，不用它替代 C 语言动手训练。

## 训练规则

1. 第一次必须从空白写，不查资料。
2. 编译后按错误类别逐个修正，不整段复制答案。
3. 每题至少包含正常、边界和反例测试。
4. 当天订正后，第二天再次从空白重写。
5. 连续两次独立通过才进入下一层数据结构实现。
