## 逐题反馈

### 1. 逻辑结构与存储结构（2 / 2）

回答抓住了关键：逻辑结构描述数据元素之间的抽象关系，存储结构描述这些关系在计算机中的实现方式。后续需要补充四类基本逻辑结构以及常见存储结构的完整分类。

### 2. 数组随机访问（1.5 / 2）

已经知道数组元素连续存储。还需要补上关键推导：同类型元素大小固定，因此第 `i` 个元素的地址可以由首地址直接计算：

```text
address(i) = base_address + i * sizeof(element)
```

不需要从第一个元素逐个寻找，所以访问时间是常数级。

### 3. 顺序表头部插入（1 / 2）

移动 `n` 个原有元素回答正确。需要建立复杂度表达：操作次数与 `n` 成正比，因此时间复杂度为 `O(n)`。

### 4. 单链表的 next（1 / 2）

末尾节点的 `next` 为 `NULL` 回答正确。术语需要修正：`next` 保存的是“下一个节点的地址”，不是“下一个头节点”。一条带头节点的单链表通常只有一个头节点。

### 5. 双重循环复杂度（2 / 2）

回答正确。内层执行总次数为：

```text
0 + 1 + 2 + ... + (n - 1) = n(n - 1) / 2
```

忽略常数与低阶项后，时间复杂度为 `O(n^2)`。
