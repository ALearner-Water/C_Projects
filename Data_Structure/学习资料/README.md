# 数据结构学期学习中心

本目录是 2026-2027 学年第 1 学期的数据结构学习入口。教学按照“学期总控—周学习包—每日任务—验收证据—滚动复测”运行；计划可以调整，但只有学生的答题、手算、代码或运行结果能够证明完成。

## 每次学习从这里开始

1. 先查看 [`学习管理/进度看板.md`](学习管理/进度看板.md)，确认当前模块和唯一下一步。
2. 查看 [`学习管理/滚动复测队列.md`](学习管理/滚动复测队列.md)，优先处理到期或逾期复测。
3. 打开当前周的学习包，按顺序完成当天核心任务。
4. 提交口述、手算、代码或运行结果，由教练按验收标准判断。
5. 结束时更新进度、错题、复测日期和下一步；没有证据不标记完成。

制定当天或本周安排前，还必须读取跨项目共享学习约束。数据结构项目只管理本项目内容，不读取或修改其他项目的学习日志。

## 状态的唯一来源

- 当前学习状态以 `进度看板.md` 为准。
- 下次复习日期以 `滚动复测队列.md` 为准。
- 错误是否已回炉以 `错题记录.md` 为准。
- 每日任务文件保存下发时的计划，不因后来超前或顺延而重写；实际结果统一写入当周 `README.md` 的“本周结算”。
- “看过”“听懂”“以前写过”和自我感觉不能单独作为完成证据。

## 一周的固定闭环

1. 周初：根据教师实际进度、复测队列和跨项目总负荷，选择最多三个周目标。
2. 周中：每次只安排一个主知识点，并混入 10-25 分钟到期复测。
3. 实现：从空白完成 C17 代码，覆盖适用的正常、边界和非法情况。
4. 迁移：完成一道适合当前能力的教材题或 LeetCode 题，不以数量代替掌握。
5. 周末：周六上午或其他无冲突时段优先完成周测；非优先时段默认不主动安排高强度任务。若学生明确确认时间与精力允许，可以用小而完整的学习单元灵活推进，并设置清晰停止点。
6. 结算：记录完成证据、顺延项、薄弱点和下周唯一第一步。

## 完成标准

一个知识点至少经过定义或不变量说明、手工追踪、独立实现、测试、复杂度分析和一次主动回忆，才算完成初次学习。新主题默认通过 D+3、D+10 和 D+30 复测后，才能标记为“已掌握”；简单内容可以在后续综合任务中自然抽查，但仍需留下证据。2026-09-09 前已经建立的旧复测日期保留为历史安排，不伪造或回写。
