# 学期路线（启动版）

本路线按照教材 8 章组织，并根据任课教师实际进度滚动调整。

| 阶段 | 教材内容 | 核心能力 | 主要实践 |
|---|---|---|---|
| 启动 | 第 1 章 绪论 | 基本术语、ADT、时间与空间复杂度 | 复杂度判断、C 基础诊断 |
| 线性结构 | 第 2 章 线性表 | 顺序表、单链表、循环链表、双向链表 | 手写基本操作、LeetCode 27/203/206/21 |
| 受限线性结构 | 第 3 章 栈和队列 | 栈、队列、递归应用 | LeetCode 20/150/225/232 |
| 串与数组 | 第 4 章 串、数组和广义表 | 模式匹配、矩阵存储、多维数组 | LeetCode 28/344/54/48 |
| 非线性结构一 | 第 5 章 树和二叉树 | 遍历、线索、哈夫曼树、树森林转换 | LeetCode 94/102/104/226/110 |
| 非线性结构二 | 第 6 章 图 | 存储、遍历、生成树、最短路、拓扑排序 | LeetCode 200/733/207/997 |
| 检索 | 第 7 章 查找 | 顺序、折半、树表、散列表 | LeetCode 704/35/33/153 |
| 排序与综合 | 第 8 章 排序 | 各类排序、稳定性、复杂度比较 | LeetCode 912/75/215/56/148 |
| 收束 | 课程设计 | 分析、设计、实现、测试、说明文档 | 完成并答辩一个综合项目 |

## 课表驱动节奏

- 第 1-3 周：每周两次理论课，建立基础并进入线性表。
- 第 4 周：数据结构理论课暂停，用于 C 指针与线性表阶段测试。
- 第 5-8 周：继续理论学习并形成稳定做题节奏。
- 第 9-12 周：每周两次理论课加一次实验课。
- 第 13-16 周：周一理论课加周四实验课，强化综合实现。
- 第 17 周：课程设计。

章节与周次不做硬绑定；每次课后以教师真实教学进度更新。
