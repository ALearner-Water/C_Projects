## 固定学习闭环

1. 直觉：观看指定视频片段，带着问题暂停思考。
2. 课前：阅读指定小节，完成概念预测题。
3. 课堂：记录不理解的概念和教师强调内容。
4. 课后：闭卷回忆，再对照教材修正。
5. 编程：用 C 语言实现核心操作并完成 LeetCode。
6. 测试：每周限时测试，错题进入错题记录。
7. 回炉：错题在 1 天、7 天和 21 天后重做。

## 和学习教练的约定

在对话中可以直接使用这些指令：

- `开始预习`：生成下一次课的预习材料和检查题。
- `开始复习`：根据课堂内容进行闭卷回忆和纠错。
- `开始做题`：按当前水平安排 LeetCode，不直接泄露完整答案。
- `给我提示`：只给一级提示；再次请求才逐级增加提示。
- `开始周测`：生成限时、闭卷的本周测试。
- `记录错题`：把错误原因和回炉日期写入项目。
- `更新进度`：同步本周实际课堂进度和完成情况。
