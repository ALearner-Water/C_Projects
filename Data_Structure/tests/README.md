# 测试区

此目录用于保存跨模块测试和综合测试。

单个数据结构的紧密相关测试优先放在其实现目录中；需要同时验证多个模块时，再放到这里。

## 覆盖矩阵

根据接口适用范围选择测试，不要求为不适用的结构机械制造用例。通常至少考虑：

- 空结构
- 单元素
- 正常多元素
- 首尾位置
- 非法位置或无效参数
- 重复元素
- 动态内存释放

每个公开操作还应说明：输入条件、成功结果、失败结果、结构是否被修改，以及由谁释放内存。

## 文件与执行

- 单模块测试命名为 `test_<module_name>.c`，与实现放在同一模块目录。
- 跨模块或章节综合测试放在本目录，并在文件顶部写明覆盖范围。
- 使用项目统一的 C17 警告选项编译；具体命令见 [`../docs/开发与验收指南.md`](../docs/开发与验收指南.md)。
- 运行成功应返回退出码 0。断言失败、崩溃、越界、重复释放或内存泄漏均不算通过。

## 验收记录

提交验收时至少保留：编译命令或工具、零警告结果、测试用例、实际输出，以及动态内存的分配与释放说明。只展示一次正常输出不能证明边界正确。
