# C 语言基础练习

此目录保存进入数据结构课程前后所做的 C 语言练习，当前按练习日期组织。

## 目录说明

- `2026_07_23/`：数组、指针、动态内存等早期练习。
- `2026_07_24/`：头文件、宏、结构体、字符串和指针数组等练习。
- `2026_09_01/`：数据结构课程开始后的 C 语言复健。

## 编码约定

- 使用 C17。
- 新文件使用有意义的英文小写名称，单词之间用下划线连接。
- 每个练习至少包含正常输入和一个边界输入。
- 编译生成的 `.exe` 不提交到 GitHub。
- 日期目录保留学习轨迹；同一主题的成熟版本以后可迁移到数据结构模块中。
