# C 语言与数据结构学习仓库

本仓库用于记录黄奕涵的 C 语言代码练习和 2026-2027 学年第 1 学期数据结构学习过程。

## 两个主要区域

- [`C_base/`](C_base/README.md)：C 语言基础与复健练习，按日期保留学习轨迹。
- [`Data_Structure/`](Data_Structure/README.md)：数据结构教材代码、LeetCode、学习资料、测试与课程设计。

## 通用约定

- C 语言标准统一使用 C17。
- 编译产物、调试文件和 `tmp/` 临时内容不提交到 GitHub。
- 学习代码先保证正确和可测试，再逐步拆分为 `.h`、`.c` 和测试文件。
- 原始练习允许保留错误与改进痕迹，成熟实现另行整理，不直接覆盖学习过程。
